# 산출물 실제 경로

뷰어가 평탄한 파일만 보여주므로 아래 이름으로 펼쳐 두었다. `∕` 가 디렉터리 경계다.

| 뷰어에 보이는 이름 | 레포에서의 실제 경로 |
|---|---|
| `challenge-domain∕test∕ChallengeTest.kt` | `challenge/domain/src/test/kotlin/com/ruleup/challenge/domain/entity/ChallengeTest.kt` |
| `challenge-domain∕test∕CreateChallengeCommandTest.kt` | `challenge/domain/src/test/kotlin/com/ruleup/challenge/domain/entity/CreateChallengeCommandTest.kt` |
