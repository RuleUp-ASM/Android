어떻게 돌렸나. 1회차는 개발용 토큰으로 만든 테스트 계정, 2회차는 사용자가 에뮬레이터에서 직접 구글 로그인한 계정으로 돌렸다. 화면은 에뮬레이터에서 눌러 확인했고, 요청·응답 본문은 앱 logcat(HttpClient)을 파일로 받아 판정했다. 2회차에서 다시 본 항목은 표의 회차 열에 '2회차'로 적었고, 나머지는 1회차 판정을 그대로 뒀다.

미실행은 건너뛴 것이 아니라 이 조건에서 만들 수 없는 상태다. 계정이 하나뿐이라 초대·수락·신고 대상이 없고, 운영 권한이 없어 정지·잠금·강퇴·티어 강등을 만들 수 없고, 새로 만든 챌린지는 모두 다음 날 시작이라 오늘 판정·자정 경계·사이클 종료가 필요한 항목은 시간이 지나야 한다. 항목마다 사유를 적었다.

코드 근거 판정. 기기에서 흐름 자체를 만들 수 없지만 코드로 결과가 확정되는 항목(예: 위치·건강 개별 동의 요청 경로 부재)은 판정과 함께 '코드 근거'라고 적었다.

이번에 찾은 결함.

  1. 이미지 업로드 전면 실패 — AndroidImageReader 가 inJustDecodeBounds 모드의 decodeStream 반환값(항상 null)을 실패로 보고 예외를 던진다. 문의 첨부·프로필 사진·챌린지 이미지·인증이 같은 리더를 쓴다(CS-06·CS-07·CRE-13).
  2. 운영 도메인 assetlinks.json 이 템플릿(REPLACE_ME) 그대로 — 실기기에서 초대 링크가 앱이 아니라 브라우저로 열리고, 웹의 /w·/c 는 404(NAV-01·NAV-05).
  3. 앱이 떠 있을 때 들어온 링크(onNewIntent)는 인증 게이트를 거치지 않아 로그아웃 상태에서 감시자 수락 화면이 뜬다. 로그아웃 콜드스타트의 초대 링크는 로그인 후 버려진다(NAV-10·NAV-03).
  4. 콜드스타트 토큰 갱신이 스플래시 AutoLogin 과 TokenAuthenticator 두 경로로 동시에 나가 한쪽이 401 을 받는다 — 21:50 에는 실제로 로그아웃됐다(AUTH-09).
  5. 프로필 저장 PATCH /v1/profile 이 스테이징에서 405 — 관심 분야 변경이 저장되지 않는다(MY-02).
  6. 방 상세 탭 줄이 깨져 피드 탭에 들어갈 수 없고 랭킹 탭은 화면 끝을 눌러야 열린다 — 탭 밑줄 Box 의 fillMaxWidth(ROOM-01).
  7. 솔로 방은 room 을 불러오지 않아 방장 수정·삭제 메뉴, 권한 끊김 배너, 장소 등록 진입점이 모두 없다(CRE-16·ROOM-14·VER-06·SETUP-02).
  8. 생성 직후 권한 요청이 사용기록 같은 특수 권한을 '낙관적 허용'으로 건너뛰고, 개인 인증 설정으로 가지 않는다(CRE-14·CRE-15). 위치·건강 개별 동의를 첫 사용 시점에 받는 경로가 없다(ONB-14·ONB-15).
  9. 알림 딥링크 ruleup://challenges/{id}/setup(복수형)을 앱 해석기가 모른다 — 권한 재허용 알림을 눌러도 이동하지 않는다(NOTI-09).
  10. 신고로 CHALLENGE_MASKED 가 와도 홈·방 화면에 가림이 적용되지 않는다. 사용자 신고 진입점이 없다(REP-06·REP-01·REP-02).
  11. 홈이 COMPLETED 챌린지를 '진행 중 · 오늘 시작'으로 보여 주고, 마이 홈 진행 중 카운트도 목록과 어긋난다(MY-01).
  12. 오프라인·조회 실패 표기: 마이 홈이 원시 예외 문구를 노출하고 재시도가 없다, 캘린더는 실패를 빈 달로 보여 준다, 홈은 백그라운드 복귀 시 갱신하지 않는다, 생성 입력은 프로세스 사망 후 사라진다(ENV-01·ENV-02·MY-06·ENV-04·ENV-05).
  13. 뒤로가기가 직전 탭으로 가고 홈으로 바로 오지 않는다(NAV-07).
  14. 문구·표기: 목표값 라벨 영어 'Target time'·숫자 키패드 시각 입력(CRE-12), 나가기 다이얼로그 '다시 참여할 수 없어요'(정책은 1주 대기, ROOM-13), 중도 참여 사이클 안내 없음(JOIN-14), 문의 접수 시각 9시간 어긋남(CS-12), 마케팅 동의 처리 시각 미표시(NOTI-07).
  15. 수동 인증 해제 버튼이 재진입 후 동작하지 않는다 — verifications/today 가 verificationId 를 주지 않음(MAN-09, 1회차).
  16. 서버 쪽 관찰: 앱 표준 sync 페이로드가 400 INVALID_SIGNAL_PAYLOAD, 미설정 대상 앱 조회가 400 SCREENTIME_NOT_CONFIGURED, 챌린지 목록 filter=IN_PROGRESS 와 home.counts 불일치.
